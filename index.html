    Créditos

      O que cada casa faz

        Gerenciador de Perguntas

        Cole seu JSON de perguntas ou edite o existente. Salve para usar nas próximas partidas.

        Regras do Jogo

        Objetivo

        Seja o primeiro a chegar à última casa respondendo perguntas e superando eventos especiais.

        Fluxo da Rodada

        1. Clique em "Rolar Dado"
        2. O dado gira e mostra um número (1-6)
        3. Seu peão avança pelo tabuleiro
        4. Responda a pergunta se cair em casa normal
        5. Acertou? Bônus! Errou? Penalidade!

        Casas Especiais

        Avançar - Avance 2 casas extras
        Voltar - Volte 2 casas
        Pular Vez - Próximo jogador perde a vez
        Trocar - Troque com o último colocado
        Bônus 2x - Pergunta vale o dobro

        Multiplayer P2P

        O Host cria uma sala e compartilha o código. Convidados digitam o código para entrar. Conexão direta via WebRTC.

        Formato JSON

        {
  "nomeBaralho": "Meu Baralho",
  "perguntas": [
    {
      "categoria": "Geral",
      "tipo": "multipla_escolha",
      "pergunta": "Pergunta?",
      "opcoes": ["A", "B", "C", "D"],
      "respostaCorreta": 0,
      "tempoSegundos": 20,
      "efeitoCasa": {"acerto": "avancar_1", "erro": "voltar_1"}
    }
  ]
}
